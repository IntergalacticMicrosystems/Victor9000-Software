# mouse

**Superseded.** This driver has been replaced by the CuteMouse port for the Victor 9000:
https://github.com/IntergalacticMicrosystems/ctmouse_v9k

Use CuteMouse for new installs. What remains here is kept for reference: the byte-exact annotated
NASM source of the original Victor serial mouse driver (MOUSE.DEV from the RAT disk), a MOUSE.COM
TSR build of it, and a description of its INT 33h API and hardware use (see `MOUSE_DRIVER.md`).
